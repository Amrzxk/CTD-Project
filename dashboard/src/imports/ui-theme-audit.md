Perform a full UI consistency and theme audit across the entire Cyber Threat Detection web platform.

Review all pages and components to ensure the design is visually consistent, clean, and comfortable for the user.

The goal is to standardize the design system and remove any visual inconsistencies.

Tasks to perform:

1. Color System Review

Analyze all colors used across the application and ensure they follow a unified cybersecurity theme.

Primary theme:
dark navy / deep blue backgrounds

Accent colors:
neon green
cyan
red for malicious alerts

Check for color conflicts and adjust any colors that feel too bright, too dark, or visually inconsistent.

Ensure charts, buttons, icons, cards, and alerts use the same color palette.

2. Theme Consistency

Ensure every page follows the same visual theme including:

background gradients
card background color
border styles
shadow styles
hover effects

Remove any components that look darker or lighter than the rest of the UI.

3. Layout and Grid Alignment

Audit all page layouts and fix any spacing or alignment issues.

Ensure all sections follow a consistent grid system.

Standardize:

card padding
section spacing
chart margins
component alignment

Make sure components align cleanly across all pages.

4. Typography

Standardize text styles across the application.

Ensure consistent usage of:

page titles
section headers
table headers
body text

Fix any inconsistent font sizes, weights, or spacing.

5. Chart Styling

Ensure all charts follow the same visual style.

Standardize:

axis colors
grid lines
tooltip styles
bar colors
line chart styles

Avoid mixing too many colors unless necessary.

6. Component Consistency

Review all reusable UI components including:

cards
tables
buttons
charts
panels
alerts

Ensure they all follow the same design language.

7. Visual Comfort

Adjust contrast, brightness, and spacing where necessary so the interface feels balanced and easy on the eyes.

Avoid harsh color combinations or heavy visual noise.

Final goal:

Produce a clean, consistent cybersecurity dashboard UI where every page feels like part of the same professional system.
